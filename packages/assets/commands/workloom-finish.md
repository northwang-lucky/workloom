# 收尾

1. 列出活跃任务、git 状态与近期提交。
2. 检查脏文件：仍属当前任务未提交 → 拒绝收尾并退回 2.3 提交；属其他窗口工作 → 报告后继续；不确定 → 问一次。
3. 归档：活跃任务执行归档；其他已完成任务经一次性确认后归档。
4. 记录：调用 journal 记录本次会话（标题 + 工作提交 hash + 摘要）。

完成判据：任务已归档、journal 已记录、git 历史顺序为工作提交 → 归档提交 → 记账提交。
