# 评测证据归档包装说明

- 评测运行目录中的项目由 `build-fixtures.mjs` 动态创建，运行时各自包含临时 `.git` 仓库。
- 归档到主仓后，这些嵌套仓库会变成 Git 子仓库引用，无法直接阅读其中的证据文件。
- 已移除 27 个生成项目的 `.git` 目录，保留全部 CASE、RESULT、会话 JSONL、覆盖率、评分和文本证据。
- 原始项目 HEAD 与代码指纹仍记录在 run.json、CASE 和 RESULT 中；归档后的普通文件用于阅读与复核，不再作为可继续开发的嵌套仓库。
- 不带技能材料仅作观察，不参与验收；本包装修正不改变任何评分或通过结论。
