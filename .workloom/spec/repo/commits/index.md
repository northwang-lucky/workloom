# repo/commits standards

Commit discipline for this repository.

- per-round: one commit per round of changes; no empty commits
- message: Chinese, format `<type>(<scope>): <description>`; types are feat/fix/refactor/style/test/ci/chore
- detail: when one line cannot describe it, add a body with bullets after the summary
- push: never push proactively
- counter-example: one commit mixing a feature and an unrelated doc rewrite
